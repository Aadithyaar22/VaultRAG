Part C

Running it

C1 · Run it on your own laptop

You need Python 3.12 or newer and Node 20 or newer. The database file is created and filled with demo data automatically on first start.

git clone https://github.com/Aadithyaar22/VaultRAG.git && cd VaultRAG
cp .env.example .env            # then edit .env (see below)
cd backend && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cd ../frontend && npm install && npm run build     # the server serves frontend/dist
cd ../backend && .venv/bin/uvicorn app.main:app --port 8000
# open http://localhost:8000   (log in as hannah / demo-pass, or click a demo card)

Choose how the AI answers in .env:

  • No internet / no key: LLM_PROVIDER=extractive (returns matching sentences; clearly labelled “non-generative”).
  • Real AI: keep LLM_PROVIDER=openai_compatible and put your own Groq key in LLM_API_KEY=. The default model is openai/gpt-oss-120b; older Groq models may have been retired, so if you get “HTTP 400/404” check the model name.

Developer mode: run npm run dev in frontend/ and open http://localhost:5173 (it forwards /api to port 8000). Tests: cd backend && .venv/bin/python -m pytest -q → 42 tests.

Docker: docker compose up --build (a Dockerfile and compose file are in the repo; we have not tested them on the LinuxONE server).

ImportantNever commit .env, *.pem keys, or the data/ folder. They are already in .gitignore. A leaked API key must be revoked, not just deleted from the repo.

Two traps we already fell into1) pkill -f "uvicorn app.main" typed inside an ssh '…' command also matches the SSH shell itself and kills your session. Use sudo systemctl restart vaultrag instead. 2) A background process started from an SSH command dies when the session ends; the systemd service avoids this.

C4 · After judging: lock it down

  1. Close port 8000 (command above).
  2. Turn DEMO_MODE off and restart.
  3. Change the demo passwords: run on the server, from ~/vaultrag/backend, a short Python snippet that calls auth.hash_password() and updates users.password_hash (ask the team lead; the passwords must be typed by a person, not saved in a file).
  4. Revoke the Groq key in the Groq console (it was pasted into a chat once).
  5. Delete the unused local key pair keys/linuxone_key*.

C5 · Building the server from nothing (hand-over)

  1. Create the instance in the LinuxONE portal (Ubuntu 24.04), import your SSH public key, note the address.
  2. sudo apt-get install -y python3-venv python3-pip build-essential python3-dev libxml2-dev libxslt1-dev python3-sklearn python3-numpy python3-scipy python3-joblib
  3. Copy the project: rsync the repository to ~/vaultrag (without .git, .venv, node_modules, .env).
  4. cd ~/vaultrag/backend && python3 -m venv .venv, then set include-system-site-packages = true in .venv/pyvenv.cfg (so the venv sees the Ubuntu scikit-learn), then .venv/bin/pip install -r requirements.txt. (There is no scikit-learn download for s390x, which is why it comes from apt.)
  5. Create ~/vaultrag/.env (chmod 600) from .env.example: a random VAULTRAG_SECRET, LLM_PROVIDER, key and model.
  6. Create the systemd unit (run as linux1, working directory backend/, ExecStart=.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000, Restart=always), then systemctl enable --now vaultrag.
  7. Open the port: sudo iptables -I INPUT -p tcp --dport 8000 -j ACCEPT and save with iptables-save > /etc/iptables/rules.v4.
  8. Check: curl http://localhost:8000/api/health should show "ml_available":true.

C7 · Troubleshooting

SymptomLikely cause → fix
Browser says “Website not available” (a Sophos page)The venue network blocks raw-IP sites. Use the SSH tunnel (C3) and open localhost:8001. Also check you typed http:// and :8000.
Browser says “Not secure”Normal: the site uses plain HTTP, no certificate.
Chat shows “model not configured”No LLM_API_KEY. Set it, or use LLM_PROVIDER=extractive.
Chat shows “model request failed after retries (HTTP 4xx/5xx)”Groq rate limit or a wrong model name. Wait a minute; check the HTTP code in the message; check LLM_MODEL.
Answers say “nothing I may share” for a user who should have accessCheck the document’s roles in Document Vault and any personal deny; check that the user has the role (Users & Roles). It is working as designed if the role is missing.
A correct answer is blocked (uncited_answer)The AI answered without citing a source twice. Ask again; if it repeats, look at llm.py prompt.
Upload fails with 422 “unreadable text”The PDF is scanned images or uses odd fonts we cannot read. Upload a text-based version.
Everyone shows “high” riskMany automated test questions in 10 minutes. The detector is rate-based; reset or wait.
Background does not moveThe computer has Reduce motion on (System Settings → Accessibility → Display). The pointer still moves it a little.
Server not answeringIf the instance does not reply to ping or SSH, stop and start it in the LinuxONE portal (Manage Instances).
Disk filling upThe IBM Jupyter image is about 10 GB. docker images; remove unused images.
Tests fail after changing retrieval or permissionsRead the failing test name: the security tests (test_security.py) describe the rule that was broken.
